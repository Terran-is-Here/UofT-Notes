# Lecture Notes
### While Loops 
While loops run under the following logic within it's definition is true: 

```python
while <condition>; 
	#do something
```
i.e. while \<condition> remains true, `#do domething` still does something, note that every time it loops over, \<condition> is run / executed. Note that this includes any executable code that would fit on one line, such as 
```python
while not print("print something"): 
	#do something
```
This code would then continuously print "print something", as bool(print()) resolves as `False`.
