# Lecture Notes
## Lists 
Lists are defined as a \[1D\] Array. One way you can think of these is that this is a List in Java, which implements the Iterable class.

```python
myList = [0,1,2,3]
```
Note that Lists in Python are zero-indexed. Lists can also be combined together with any kind of object (string, function, class, etc.)  

Note that unlike Java's ArrayLists, we do not need to explicitly define their Classes: 
```java
const MY_LIST = new ArrayList<String>()
```
