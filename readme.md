Hello! This GitHub repository serves as my online drive for my Engineering Science notes at University of Toronto. I do not give a guarantee for the quality of these notes, as these were predominantly for my own use. As of time of writing, I currently do not have any plans to make a finalized "revised" note set for use, however that might change in the future when I finally get some free time to think about it. 

## Textbooks & Materials
As to make sure that this drive does not get taken down, digital textbooks are not included within this repository. Some links within some notes will likely be broken because of it. 

As of time of writing (2026-11-19), I have **not** included some of the related course materials online for some of the courses that we have taken (such as past assignment sets, etc.); as I do not know if I have permission to share & store these materials online on a GitHub repository. This will be updated in the future if things change. 

## Accessing Notes
> Notes present within this repository have been primarily written in [Obsidian](https://obsidian.md/), and I highly recommend using it as a relatively lightweight notetaking tool. It is highly advised to navigate this note repository using Obsidian, as most of the formatting should apply there. 

* Notes are sorted in terms of the term in their folder names (so, "3T0 26F Notes" -> 2026 Fall Notes). 
	* These folders are subdivided into a "Dump" folder, and a "Hub" folder. 
* Dump folders contain all the actual notes for that corresponding school term, in a flat directory structure. 
	* Notes are sorted and queried by their corresponding frontmatter entries.
	* Notes *should* have the naming convention of "##  — Topic", where the number roughly corresponds to a lecture number / unit number.
		* I will say though, it's more so just which note number is this in the sequence) 
* Hub folders contain navigation notes which **use obsidian's query** tools to dynamically fetch the current notes present. 

### Other Folders
* The "Attachments" folder generally contains images and other things that I randomly paste onto this note space.
* The "Templates" folder contains the templates that I use to create my notes.
