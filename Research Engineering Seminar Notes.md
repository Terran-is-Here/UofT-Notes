## What *is* research? 
* The general point of research is to uncover new information. 

In terms of how it could look like: 
* Theoretical / Computational
	* In this case, this would be like sitting and modelling a model and seeing if it correlates with pre-established models and or theoretical models. 
* Experimental (Lab) 
* Observational (Field / Clinical) 
	* This would be going into a field, getting information / data to which apply a model to in order to infer information. 
* Technique / Instrument Development

Recall that Research is not purely isolation, Research *and* Development exists as an Acronym for a reason (where these focus more on industry-applicable research) 

### Undergraduate Research
Great way to learn and apply theory / learn new theories! 
* Field-specific skills (instrument operation / process / techniques in field) 
* General technical skills (dealing with large datasets / using technical software)

	* Uncertainties (and how to handle them)
